# Варианты лабораторной работы №1

Каждая пара получает один вариант целевой функции.

Для функции своего варианта необходимо реализовать **все три метода одномерного поиска**:

1. метод дихотомии;
2. метод золотого сечения;
3. метод Фибоначчи.

Для методов дихотомии и золотого сечения минимум необходимо найти с заданной точностью $\Delta$.

Метод Фибоначчи необходимо запустить с тем же количеством вычислений целевой функции, которое потребовалось методу золотого сечения.

## Точность поиска

При необходимости исследуйте несколько значений $\Delta$: на некоторых функциях различия между методами становятся заметны только при достаточно высокой точности.

Для метода дихотомии величина $\varepsilon$ выбирается самостоятельно как малая положительная величина по сравнению с $\Delta$.


## Что необходимо сделать

Для функции своего варианта:

1. Построить график функции на заданном отрезке.
2. Реализовать метод дихотомии.
3. Реализовать метод золотого сечения.
4. Найти минимум обоими методами с одинаковой точностью $\Delta$.
5. Сравнить количество вычислений целевой функции.
6. Реализовать метод Фибоначчи.
7. Запустить метод Фибоначчи с тем же количеством вычислений функции, которое потребовалось методу золотого сечения.
8. Сравнить достигнутую точность золотого сечения и метода Фибоначчи.
9. Представить результаты в таблице и сделать краткие выводы.
