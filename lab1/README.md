# Лабораторная работа №1

## Одномерный поиск и градиентный спуск

## Цель работы

Изучить методы поиска минимума функции одной переменной, реализовать один из методов одномерного поиска, а затем реализовать градиентный спуск и применить его к обучению простой модели машинного обучения.


## 1. Теоретический минимум

### Одномерная оптимизация

Задача одномерной оптимизации состоит в поиске точки $x^*$, в которой функция принимает минимальное значение на заданном отрезке:

$$
x^* = \arg\min_{x\in[a,b]} f(x).
$$

В этой работе рассматриваются унимодальные функции, для которых на отрезке поиска имеется один минимум.

### Методы поиска

**Метод дихотомии** сравнивает значения функции в двух точках, расположенных около середины текущего интервала, и отбрасывает часть интервала, в которой минимум находиться не может.

**Метод золотого сечения** выбирает точки так, чтобы на следующей итерации можно было повторно использовать одно из уже вычисленных значений функции.

**Метод Фибоначчи** использует последовательность чисел Фибоначчи для выбора точек, в которых вычисляется функция, и последовательного сокращения интервала поиска.

### Градиентный спуск

Если производная функции известна, можно использовать градиентный спуск:

$$
x_{t+1}=x_t-\eta f'(x_t),
$$

где $\eta$ — learning rate, или шаг обучения.

Для функции нескольких переменных обновление записывается как

$$
\theta_{t+1}=\theta_t-\eta\nabla L(\theta_t).
$$

## 2. Часть A. Одномерный поиск

### Задание A1. Целевая функция

Получите номер варианта. Для каждого варианта заданы:

- целевая функция $f(x)$;
- отрезок поиска $[a,b]$;
- метод одномерной оптимизации.

Варианты приведены в [отдельном файле](variants.md).

Постройте график функции на заданном отрезке и укажите предполагаемое положение минимума.

### Задание A2. Реализация метода

Реализуйте метод одномерного поиска, указанный в вашем варианте:

- метод дихотомии;
- метод золотого сечения;
- метод Фибоначчи.

Алгоритм должен находить минимум функции на заданном отрезке с точностью

$$
\Delta = 10^{-3}.
$$

Остановка алгоритма должна происходить, когда длина текущего интервала поиска становится не больше заданной точности:

$$
b_k-a_k \leq \Delta.
$$

Для метода дихотомии используйте

$$
\varepsilon = \frac{\Delta}{4}.
$$

Для метода Фибоначчи предварительно определите необходимое число шагов $N$, достаточное для достижения заданной точности $\Delta$.

В процессе работы алгоритма сохраняйте:

- текущий интервал поиска;
- точки, в которых вычисляется функция;
- количество итераций;
- количество вычислений целевой функции;
- итоговую точку минимума;
- итоговое значение функции.

### Задание A3. Результат

Для своего метода:

1. Найдите минимум функции.
2. Укажите найденную точку $x^*$.
3. Вычислите $f(x^*)$.
4. Укажите количество итераций.
5. Укажите количество вычислений целевой функции.
6. Постройте график изменения длины интервала поиска.
7. Сделайте краткий вывод о работе метода.

## 4. Часть C. Применение в машинном обучении

### Задание C1. Данные

Сгенерируйте синтетический набор данных:

$$
y=2x+1+\varepsilon,
$$

где $\varepsilon$ — случайный шум.

Используйте не менее 100 объектов и зафиксируйте random seed.

Постройте график полученных данных.

### Задание C2. Линейная регрессия

Реализуйте модель

$$
\hat y=wx+b
$$

и функцию потерь MSE:

$$
L(w,b)=\frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2.
$$

Аналитически выведите и реализуйте градиенты по $w$ и $b$.

### Задание C3. Обучение

Обучите модель с помощью собственного градиентного спуска.

Во время обучения сохраняйте:

- значения $w$ и $b$;
- значение функции потерь на каждой итерации.

Постройте:

- график функции потерь;
- график данных и полученной прямой регрессии.

Сравните найденные параметры $w$ и $b$ с параметрами, использованными при генерации данных.

Кратко объясните:

- что в этой задаче является параметрами модели;
- что является функцией потерь;
- что является результатом оптимизации.
